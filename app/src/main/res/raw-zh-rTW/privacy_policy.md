# 隱私權政策

生效日期：2026-08-26

## 1. 我們是誰

本應用（"OSS Browser for Android"）是一款開源的阿里雲物件儲存客戶端。
應用原始碼遵循 Apache License 2.0 開源。

## 2. 我們如何處理您的資訊

本應用自身**不收集、不分析**使用者的個人資料、使用行為或裝置識別碼。您主動開啟的
連網功能可能存取下述服務。

- **金鑰（AccessKey ID / Secret）**：透過 Android Jetpack Security
  （`EncryptedSharedPreferences`）僅儲存在**本機**，AES-256 加密。
  不會上傳至任何第三方伺服器。
- **OSS 請求**：所有 OSS 相關請求**直連阿里雲 OSS endpoint**（如
  `*.aliyuncs.com`），由阿里雲 SDK 處理。請求內容與阿里雲之間的隱私關係
  以阿里雲《個人資訊保護政策》為準。
- **阿里雲網頁控制台**：開啟此選用頁面後，內建 WebView 會直接連線阿里雲 HTTPS
  網域。App 只儲存帳號類型和帳號名稱供下次預填；WebView 會保留阿里雲 Cookie
  和網站儲存空間以延續登入工作階段。本 App 不讀取或儲存密碼及 MFA 驗證碼；
  可用時由系統自動填入服務負責儲存或填寫密碼。開啟診斷時，App 會在記憶體中讀取
  目前網站 Cookie，並立即丟棄完整值，只保留 Cookie 名稱和不可逆的星號脫敏值；
  預設設定會進一步隱藏該脫敏值。完整 Cookie 值不會寫入日誌、設定或診斷複製內容。
- **網頁瀏覽核心**：您可以在系統 WebView 與隨應用程式安裝的 Mozilla GeckoView 之間選擇。
  GeckoView 不會在執行時下載瀏覽器核心，其 Cookie 和網站資料儲存在應用程式私有目錄；
  Debug 版本允許透過 USB 遠端偵錯，正式版本關閉此能力。
- **夏日晴空主題**：選擇該主題後，應用會從 `haowallpaper.com` 下載桌布；
  對方伺服器可能收到 IP 位址等一般網路資訊。Coil 會將圖片保存至應用私有快取，
  供後續優先在本機使用。
- **完整 HTML 預覽**：安全靜態預覽不會載入外部資源。您為目前檔案明確開啟完整
  網頁預覽後，其中的 JavaScript 與 HTTPS 外部資源可能存取 HTML 指定的第三方網域。
- **預覽與主題快取**：圖片預覽和夏日晴空桌布使用 Coil 在本機暫存；可在「設定 → 清除快取」
  處隨時清理。
- **當機 / 統計**：本應用**不整合任何第三方統計、當機回報、廣告、埋點 SDK**。

## 3. 您對自身資料的控制

- 所有金鑰、偏好設定均保存於應用私有目錄；**解除安裝應用**即會被系統一併移除。
- 也可在「金鑰」頁逐項刪除 OSS 配置。
- 可在網頁控制台選單中清除阿里雲 Cookie、網站儲存空間、歷史記錄和 WebView
  快取；此操作不會刪除供下次預填的帳號名稱。

## 4. 權限說明

- **網路權限**：存取阿里雲 OSS 及選用網頁控制台、下載夏日晴空桌布，以及載入您在
  完整 HTML 預覽中明確允許的外部資源
- **讀取 / 寫入檔案**：透過系統「儲存存取架構（SAF）」選擇檔案進行上傳 / 下載；
  應用本身不會掃描您的檔案系統
