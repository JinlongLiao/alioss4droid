# 隐私政策

生效日期：2026-08-26

## 1. 我们是谁

本应用（"OSS Browser for Android"）是一款开源的阿里云对象存储客户端。
应用源码遵循 Apache License 2.0 开源。

## 2. 我们如何处理你的信息

本应用自身**不收集、不分析**用户的个人数据、使用行为或设备标识。你主动开启的
联网功能可能访问下述服务。

- **密钥（AccessKey ID / Secret）**：通过 Android Jetpack Security
  （`EncryptedSharedPreferences`）仅保存在**本机**，AES-256 加密。
  不会上传到任何第三方服务器。
- **OSS 请求**：所有 OSS 相关请求**直连阿里云 OSS endpoint**（如
  `*.aliyuncs.com`），由阿里云 SDK 处理。请求内容与阿里云之间的隐私关系
  以阿里云《个人信息保护政策》为准。
- **完整 HTML 预览**：安全静态预览不会加载外部资源。你为当前文件明确开启完整
  网页预览后，其中的 JavaScript 与 HTTPS 外部资源可能访问 HTML 指定的第三方域名。
- **预览与主题缓存**：图片预览使用 Coil 在本地临时缓存；可在"设置 → 清除缓存"
  处随时清理。
- **崩溃 / 统计**：本应用**不集成任何第三方统计、崩溃上报、广告、埋点 SDK**。

## 3. 你对自己数据的控制

- 所有密钥、偏好设置均保存于应用私有目录；**卸载应用**即会被系统一并移除。
- 也可在"密钥"页逐项删除 OSS 配置。

## 4. 权限说明

- **网络权限**：访问阿里云 OSS 、加载你在
  完整 HTML 预览中明确允许的外部资源
- **读取 / 写入文件**：通过系统"存储访问框架（SAF）"选择文件进行上传 / 下载；
  应用本身不扫描你的文件系统
