# 文件页工具栏交互调整

## 目标与结果

文件名和列表应占据主要空间。原文件页在标题栏展示最多五个操作按钮，又在内容区常驻一整行布局切换，底部还有悬浮操作。调整后标题栏仅保留「刷新」和「更多」，其余按使用目的归组。

| 分组 | 操作 | 可用位置 |
| --- | --- | --- |
| 文件与传输 | 上传文件、新建目录 | Bucket 内 |
| 文件与传输 | 上传任务 | 所有文件页，含尚未激活配置时 |
| 浏览视图 | 视图设置 | 已激活配置的文件页 |
| 浏览视图 | 跳转到路径 | Bucket 内 |
| 存储配置 | 对象存储配置 | 所有文件页 |

「视图设置」在同一菜单锚点打开，提供返回主菜单入口：列表与双列瀑布流仍并排显示；Bucket 内额外显示四种文件排序。菜单关闭后，下次从分组主菜单重新打开。

## 节省空间与状态

- 移除内容区常驻的布局切换行。
- 上传和新建目录移入右上角，移除底部悬浮按钮。
- 对象列表不再为悬浮按钮预留额外底部空间，底部留白从 96dp 调整为 24dp。
- 不压缩按钮的标准触控区域；标题获得更多横向空间，菜单按可用高度滚动。
- 有正在执行或排队的上传时，「更多」及「上传任务」菜单项显示数量角标；入口提供包含数量的无障碍说明。
- 选择布局和排序后仍使用现有设置仓库保存；网络请求、系统文件选择器、上传任务、路径跳转和配置管理沿用原流程。
- 没有激活配置时禁止刷新，仍允许查看上传历史和管理配置；不展示无效的文件操作。

## 验证边界

运行完整 JVM 单元测试、Android Lint 与调试 APK 构建，使用独立临时构建目录，避免覆盖并行会话的报告。最终 JVM 测试共 124 项：123 项通过、0 失败、1 项跳过（未提供真实账号的 S3 连接测试）；Lint 为 0 错误、69 警告，APK 构建成功。三语言文案同步维护，执行 UTF-8、LF、行宽及 `git diff --check` 检查。

本轮未安装或操作手机，没有真实云服务写入；菜单的真机视觉、超大字体及交互仍需设备验收。没有执行 Git 提交或推送。
