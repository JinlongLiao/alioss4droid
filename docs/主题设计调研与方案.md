# 主题设计调研与方案

检索日期：2026-11-07。对象：本项目 Android 文件管理界面。目标：增加风格差异，改善列表阅读和图标一致性，保留账号、文件预览及传输行为。

以上为设计原则参考，不是跨平台组件移植，也没有为外观改动升级 Compose 或引入新 UI 框架。图标路径为本项目原创。

## 产品判断与方案

下列为针对本项目的设计判断，不代表上述产品的官方建议。

- 默认界面适合长时间浏览文件：正文层级和密度优先于装饰。
- 用户主动选择多彩、玻璃、终端或纸感时，应感受到材质、形态和字体差异，而不只是名称变化。
- 晴空应能看出天空和云层；Gemini 应有可辨识的多色渐变。
- 设置功能图标统一重绘，沿用账号、语言、备份等熟悉语义，并随主题改变容器材质。
- 新主题以枚举名保存，旧晴空枚举名保留兼容；明暗模式仍独立。

首批 18 套：云雾蓝、晴空、Gemini、青瓷、暮紫、暖砂、流光彩虹、极光、冰川玻璃、夜幕玻璃、极简黑白、像素终端、赛博霓虹、纸感书页、樱雾、松林、海盐、落日余晖。

## 验证标准

- 全部明暗组合覆盖文字、按钮、容器和多色导航的对比检查；玻璃表面与实际背景色合成后再计算。
- 玻璃、纸感、终端在透明度、圆角和导航/目录图标材质上有实质差异；文件类型图标固定，不随主题替换形状或类别色。
- 实机检查主题预览、设置图标、Bucket、文件夹、文件和长文件名布局；外发截图先遮挡敏感信息。
- 不向真实存储服务执行上传、覆盖或删除操作。切换主题不修改账号和业务数据。
