# 视觉风格与图标适配

## 设计取舍

文件管理的主体是名称、目录、大小和任务状态。界面采用中性背景、实色内容卡片和小面积强调色，减少大面积渐变、重复品牌卡片及复杂壁纸对阅读的干扰。启动图标保留已选定的青蓝、浅紫渐变和轻玻璃质感。

- 文件页突出内容列表；仅未配置账号时展示品牌引导。
- 设置与密钥页不重复展示大号品牌摘要，统一间距、圆角和文字层级。
- 底部保留文件、设置两项导航，使用单层选中指示；多彩主题采用渐变强调。
- 深色模式显式设置正文颜色；透明页面容器继承根节点的前景色。

## 配色主题

| 风格 | 主题 | 差异 |
| --- | --- | --- |
| 工具与自然 | 云雾蓝、青瓷、暮紫、暖砂、樱雾、松林、海盐 | 中性实色表面与不同强调色 |
| 天空与多彩 | 晴空、Gemini、流光彩虹、极光、落日余晖 | 天空云层、多色渐变或光晕；多彩导航强调 |
| 玻璃 | 冰川玻璃、夜幕玻璃 | 半透明内容层、亮边、更柔和的圆角与玻璃图标容器 |
| 极简 | 极简黑白 | 灰阶配色与描线图标 |
| 纸感 | 纸感书页 | 暖白底、衬线字形、细线图标和较小圆角 |
| 科技 | 像素终端、赛博霓虹 | 等宽字形、几何图标容器和硬朗圆角 |

18 套主题均提供浅色、深色方案，并与语言、文件排序及账号配置独立保存。主题选择弹窗显示真实背景、内容卡片和圆角缩略预览，切换不改变用户单独选择的明暗模式。旧 `SUMMER_SKY` 枚举名继续兼容，改用本地天空渐变和云形装饰，不再请求远程壁纸。

## 列表图标

- Bucket 使用开口存储桶，替代服务器机架。
- 文件夹采用分层开口轮廓，颜色跟随主题。
- 文件采用统一折角纸张，Android、JSON、网页、Windows 程序、磁盘镜像、安装包、PDF 等使用各自语义符号。文件图形和类别色固定，跨主题、列表及预览保持一致；完整分类见 [文件类型图标修正](文件类型图标修正.md)。
- 设置页所有功能入口均使用原创语义图标，容器随主题切换描线、柔和、玻璃与几何风格。
- 图标使用原创 Compose `ImageVector`，直接绘制原色，不叠加 Material 单色 tint 或重复底框。
- 扩展名分类和文件预览判定保持独立。

## 启动图标

原稿保存在 `设计资源/应用图标原稿.png`，页面缩略图和自适应前景分别位于：

- `app/src/main/res/drawable-nodpi/ic_launcher_artwork.png`
- `app/src/main/res/drawable-nodpi/ic_launcher_glass.png`

透明前景由内置 imagegen 从选定原稿提取并清理，之后仅按 Android 资源尺寸缩放。生产提示词要求保留云形背板、文件卡片、前层文件夹、渐变、比例和位置，只移除背景、零散像素与投影。透明层置于 108dp 画布中的 88dp 居中图层；渐变背景及单色主题图标使用 Android 原生资源。

裁切依据：[Android 自适应图标规范](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。

## 网页功能退役

移除阿里云网页控制台、System WebView 控制台页面、GeckoView 内核、会话桥接和相关设置、资源、测试。统一使用 `assembleDebug`、`testDebugUnitTest`、`lintDebug`，安装脚本同步切换 APK 路径。文件 HTML 预览中的受限 WebView 仍服务于文件预览。

旧账号和其他使用偏好不因功能退役而清理。

## 安装与恢复

手机原调试包签名与本机不同。在用户授权卸载后，先通过旧应用导出并验证加密配置，再卸载安装；原始加密偏好文件不能替代跨安装备份，因为卸载会移除 Android Keystore 密钥。

已恢复全部 3 套 OSS 配置，重新激活原配置。恢复后再次导出，在内存中解密并逐字段比较，确认与卸载前完全一致；没有将密钥或备份文件写入仓库。应用偏好另行备份恢复，视觉设置采用本次选定的新主题。
